# 4.0.0 首次体验与重看

## 行为与状态契约

- 沿用现有数据库 `onboarded` 决定是否进入首启配置。已配置设备直接进正常界面，升级不强制显示新引导。
- 首启欢迎提供「体验一次」「直接配置模型」。三站示例随时可跳过，完成或跳过后进入原模型配置。
- 引导偏好独立保存在 `localStorage["mathmyth.learning-tour.v1"]`，格式 `{version:1,status:"skipped"|"completed"}`。缺失、损坏或未知版本视为尚未体验。
- 偏好存储不可用时，本次会话仍记住选择，不阻塞模型配置；配置页明确说明重启后可能再次显示。
- 设置 → 使用帮助 → 重新体验引导，以现有模态框覆盖。退出回同一设置页，不变更路由或会话，不卸载模型配置表单。应用普通聊天草稿由主 Agent 的会话草稿状态保留。
- `LearningTour.jsx` 只引用本地演示 reducer、数学排版和模态框，不引用聊天、数据库、练习 store 或模型客户端；不产生个人收藏、足迹、作答证据、掌握度或复习安排。
- 演示仅检查固定路线选项。完整步骤批改属于配置后的真实练习；示例不会伪装自由输入批改。
- 展开提示、参考答案的事实在本次演示重试、往返各站时保留。提交结果记录当时帮助快照；之后查看帮助不倒改此前结果。
- 路线选对只说明辨认了路线，不宣称独立完成、迁移或间隔检验。未提交即可正常结束。
