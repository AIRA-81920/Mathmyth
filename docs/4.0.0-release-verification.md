# Mathmyth 4.0.0 交付与验证

2026-10-28。版本为 4.0.0，Android versionCode 为 31，学习数据库 schema 为 v11。

本次围绕已讨论的学习体验改造：让一轮讲解自然连接到可选择的练习，让用户知道目前已经做到了什么，以及还可以怎样继续。

## 已实现的用户流程

1. **看完讲解。** 对应 AI 回答末尾集中提供本题路径、相关题与收藏原题入口。入口绑定原来的那道题、那条回答和当时的路径，不会在后来追问或另一道题出现后串题。历史回答保留当时的路径快照。
2. **选择要试的思路。** 多题或多路径先选择目标。有顺序的方法显示操作先后；没有顺序证据的旧记录不会被补写成一条确定的链。
3. **试一道相关题。** 同时匹配公式结构、条件以及有顺序的情景与方法链，排除已讲过或刚做过的同一数学实例。匹配不到就明确说明，不用同标签题冒充精准匹配。
4. **按自己的方式开始。** 短练习可以直接写关键步骤，也可以先选路线。没有思路时逐层展开提示，提示留在卡片内；可以继续追问、查看解答或结束。
5. **获得有限的结论。** 认出路线与实际用出方法分别记录；只写正确结果时请求补充过程。部分操作正确会被保留，但不会据此宣称完成整条目标。正确的其他解法可以成立，同时说明原目标思路尚未检验。
6. **决定接下来做什么。** 完整检验目标操作后，才按当前题实际支持的关系提供条件对照或外形变化题。任何时候都可「先到这里」。结束卡片说明已观察到的表现和未验证部分。
7. **自愿再试。** 用户主动选择「下次再试」才产生复习安排，可撤销。练习与足迹页能找到继续入口；复习打开独立会话，使用新的题面实例，不把原题已看过的答案当作新测验。

练习草稿、提示、原始作答、帮助反馈、异议和复习安排都随本地学习记录保存。退出步骤输入会保留练习草稿并恢复原聊天草稿；重启可恢复尚未完成的练习。后来查看帮助不会抹掉此前已保存的独立成功，有帮助的后续尝试也不会被包装成无提示独立完成。

## 首批内容与覆盖范围

- 新增 23 道自编关系练习，覆盖根式差与正弦、根式差与线性项、正弦比值、平方差因式分解四类极限结构。前两类包含条件对照与外形变化；后两类只提供已准备且匹配的后续关系。
- 题面、路线、提示和解答经过结构校验、数学排版检查与两侧数值检查；包含对照题的发散情形和其他有效解法的独立推导检查。这不是外部教师逐题人工审定的声明。
- 数学内容摘要与安装题库清单绑定。调用方自行写上「已审核」或篡改题面、路线后，不能继续获得本地题库的可信身份。
- 不支持的结构、额外参数、无法辨认的条件、多个表达式歧义等会停止精准匹配。原有问答、题库与练习功能仍可使用。
- AI 变式需要用户明确选择，仍必须通过目标匹配；即使模型自行声明已审核，也只作为未验证草稿，不计入掌握度。

## 首次体验

首次启动提供「体验一次」与「直接配置模型」。三站本地示例展示回答末尾、类似题与提示，以及结束后从哪里继续；随时可以退出。演示无需 Key，不调用模型，不写个人收藏、练习、足迹、掌握度或复习安排。

已配置的旧用户升级不会被强制带入引导。设置中的使用帮助可以重新体验，退出后保留原页面和配置草稿。详细约定见 [首次体验验证](4.0.0-onboarding-verification.md)。

## 明确的验证边界

有限的测试不能证明软件绝无缺陷。本次没有调用用户的真实模型服务，没有在实体 Android 设备上安装运行，也没有验证不同 Windows 安装环境或长期大规模使用。真实模型的数学反馈仍可能有误，因此保留异议与原始证据；单次成功也不会被描述成已经稳定掌握。

数据库已升级到 v11。旧记录及旧备份按迁移规则读取；新版本导出的 v11 备份不保证能被旧版本读取。源码快照不替代用户的学习数据备份。

构建仍有原有的大题库懒加载分包体积提示，以及现有 Gradle 弃用提示，均未导致构建失败。安装包只生成在本地，尚未上传或公开发布。
