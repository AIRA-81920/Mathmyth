## 关键接口约定

- 主 Agent 在 appStore 增加 `startRelatedPractice({answerId,userMessageId,questionIndex,pathIndex,sourceItemId,reviewId,relation,ai})`，原题入口与练习后续共用。relation 为 similar / contrast / transfer。
- 题目保留现有 route-v1 格式与数据库校验；新增题目关系、提示与目标数据放在 metadata.learning 中。
- 有帮助的尝试不获得无提示独立成功；后续查看帮助不倒改已经保存的独立成功。
- 复习为用户主动选择，独立持久化，不使用临时任务队列保存学习资产。
- 演示流程不写入个人 encounter/mastery/practice 数据；跳过与完成均不主动重复出现。

不承诺通过有限检查证明零 bug；交付以实际通过的检查和明确的范围为准。
