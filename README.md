## 本次行为

- 图片先进入输入框，可删除或配文字；点发送才调用模型。模型在同一次答疑中转写题面，自动显示在原图下，再逐段输出解答。没有题面确认、完成查看或欢迎页。读错可正常追问纠正。
- 网页 SSE、安卓原生 HTTP、桌面原生 HTTP 使用同一解析器。新安卓包和桌面可物理取消连接；旧安卓插件缺失时退回原有缓冲 HTTP。服务商自身缓冲或只返回 JSON 时按其实际响应显示。
- Markdown 在完整块、代码、公式、链接和列表边界提交检查点，未闭合尾部先显示普通文字。稳定块独立记忆化，结束后用完整 Markdown + GFM + KaTeX 渲染。私有思考文本不进入可见对话；Kimi 必需的多轮上下文单独保存与回传。
- 点附件按钮先收键盘，再在输入框下展开最近图片及“拍照 / 相册 / 文件”。安卓最近图片须系统授权；拒绝授权仍可用系统选择器。网页和桌面只展示最近选用的图片。桌面拍照使用摄像头。
- 文件在本机解析：JPEG / PNG / GIF / WebP，纯文本（UTF-8、UTF-16、GB18030），.docx，Word 97–2007 .doc 主文本，PDF。PDF 对多模态模型同时保留页面图像，避免丢公式 / 图形；文本模型不处理扫描页。旧 .doc 嵌入公式 / 图形及 Word 不支持的矢量图需要另存 PDF。单文件 25 MiB、PDF 20 页、文本 8 万字符，超限说明原因，不静默截断。
- 练习围绕共同目标的完整路线：找到一条可行路线（单选）、辨认给出的可行路线（多选）、按明确标准比较路线，以及写实际关键步骤。优先本地已准备题；无本地题时可主动请求 AI 变式。AI 草稿不计入掌握度；取消保留已生成题，不自动重试付费调用。旧方法选择练习记录仍可读取。
- 认出：累计 3 次成功且 3 种结构题面；用出：累计 2 次且 2 道实际题。重复原题每维度只记一次；看答案不罚，也不记该题独立成功；已掌握答错退回巩固中并减一次，不清空题面，不按时间降级。
- 手机长按、桌面右键 / 长按历史，提供置顶、重命名、删除。删除时用户可选只删聊天或同时移除该聊天产生的足迹。只删聊天保留题面摘要及掌握度；其它聊天 / 练习的共同成绩不被清除。
- 首条内容异步生成最多 20 字的 AI 标题，手动重命名优先；题目按钮显示短标题或有长度限制的摘录。抽屉可搜索标题、聊天正文和提取的附件文字。
- 足迹展开和滚动状态全局保存，切换已有会话或返回方法页保留，创建新主会话时重置；方法叶子不显示展开箭头。方法页右下角气泡打开覆盖式聊天浮窗，单独保存讨论，沿用检查点流式渲染。
- 设置可选浅色、深色、跟随系统；浅色轻微暖白、深色主背景纯黑。主题跨重启保存。
- 后台归位不会卡住答疑，前台开始回答会立即中止后台请求，归位稍后从检查点继续。问答只暴露，掌握度只由练习更新。
- 足迹的板块、分组和情景可通过信息图标、长按或右键查看定义与特征；方法适用情景和情景关联方法可相互点击，返回保留展开与阅读位置。反向检验已废弃。
- 练习页“练习记录”集中回看原题、路线选项、当时的选择或步骤、反馈和解答。查看解答会记为已揭示，后续不计该题独立成功。
- 点待发送图片缩略图可选择裁切，拖动框/角点，或方向键微调；可取消和恢复原图。裁切按原始像素保存，发送时只提交裁切结果。文档页图继续按原文件处理。

## Android APK

已有项目内 SDK 36 / JDK 21 与 Gradle 缓存，也可传入自己的路径。App 最低 Android 7，运行不需要电脑。

```powershell
npm run android:build
```

脚本先显示当前版本和 Android versionCode，再询问本次版本；直接回车沿用当前值。换版本自动增加 versionCode，保证 Android 可升级；版本同步到设置“关于”、package 文件和原生工程。

```powershell
# 无交互构建当前版本
npm run android:build -- -NoPrompt
# 用户指定自己的版本
npm run android:build -- -Version 0.2.0 -NoPrompt
# 自定义构建工具
npm run android:build -- -SdkPath 'SDK目录' -JdkPath 'JDK21目录'
```

输出 `artifacts/Mathmyth-v版本-debug.apk`，同时打印 SHA256。仍是调试签名，不自动上传 / 发布。正式版本与签名由用户后续决定。

**安装包不带用户 Key。** 构建只包含静态代码和骨架，用户 Key 留在设备本地数据库。脚本在网页资产和最终 APK 上检查密钥、环境文件、私钥和 SQLite 备份；发现可疑内容立即阻止交付。新安装的 Key 为空，覆盖升级会保留设备已有设置。用户主动导出的 SQLite 备份包含模型设置（包括 Key），与安装包不同。

## Windows 桌面

```powershell
npm run desktop:build
```

输出 `artifacts/desktop/Mathmyth-v版本-Setup.exe`，Windows x64 NSIS 安装器。版本沿用当前项目版本；无自动更新、云同步或后台服务。桌面用户数据位于 `%APPDATA%\Mathmyth`，卸载不会主动删除学习数据。安装包尚未配置正式 Authenticode 签名。

桌面只打包 `dist`、隔离主进程 / preload 和最小 package 元数据，成品 ASAR 再检查；不包含工作区、浏览器配置、用户数据、`.env` 或 SDK。Electron 渲染进程不开 Node，使用独立安全协议，原生 HTTP 和文件导出通过窄 IPC 接口完成。关闭前先停止回答并等待本地保存。

Electron 运行时首次需下载，官方地址超时可用镜像，但必须匹配 Electron 官方 npm 包内 SHA256。运行已有构建可用 `npm run desktop:run`。

## 精简自测

1. 首启填有效 Key / 模型，按真实能力勾选图片；“测试一下”应出现真实成功或明确失败。开始后直接进入空问答。
2. 发送文字题：正文逐段出现，闭合公式正确渲染；停止后保留已收到内容。长按 / 右键回答选“这题不对”，应核查所选回答。
3. 输入框弹键盘后点附件：键盘收起，面板留在输入框下；选图仅进入附件。发送后原图立即出现，识别文字自动在图下，解答逐段出现。
4. 分别选文本、Word、PDF：显示附件名；含图文件须图片能力，解析失败给出原因。无需额外确认即可发送。
5. 进入练习：本地目标点“开练”应立即出现整题路线；基础层单选任一有效路线均可，多选层须辨别给出的所有有效路线，比较层会区分“可行”和“更符合标准”。“练习记录”重启后仍有原题和个人作答。
6. 历史长按 / 右键：置顶分组、重命名、删除选择有效。只删聊天后足迹仍在，可查看题面摘要；勾选同时删除会移除该聊天的来源记录。
7. 重开：模型设置 / 历史 / 原图恢复，同时进入新的空问答。设置 → 数据导出，然后导入同一文件，确认替换后能恢复记录；损坏备份不改旧数据。
8. 手机窄屏和系统明暗下，长公式可横滚、没有底栏或彩色标记，顶栏纯平。危险清空仍需二次确认。
9. 设置切换浅色/深色再重开：主题保留。发长题面：抽屉逐步出现短标题；搜索正文中的词也能定位。足迹展开后进入方法再返回，保持展开；点新对话才重置。
10. 方法页点右下角气泡：浮窗覆盖页面，原页面不变形；发送关于方法的问题，逐段出现回答与公式。收起重开以及从历史重开均保留讨论。
11. 足迹点“未定式极限”右侧信息图标，能读术语含义；方法页点灰色情景进入详情，再返回仍保留原阅读位置。已有骨架说明与新补的教材依据分别标注。
12. 选图后点缩略图裁切；拖动框与角点后使用，附件变成裁切图；取消保留原图，重开可恢复原图，发送无需题面确认。

98 项核心自动检查通过；新增浏览器和 Android 36 浮窗/主题/标题/搜索验证，Windows 更新成品冷启动恢复历史。前一轮桌面隔离进程也验证了 SQLite、原生流式、附件与合成摄像头。最终成品检查与证据见 [验收清单](../docs/验收清单.md)。模拟模型用于验证传输与状态，不代表真实数学质量；实际服务商典型性和物理手机仍需实测。

## 服务商与提示词

五家地址保留用户提供值，默认模型可编辑，图片能力由用户勾选，切换预设不替用户改变开关。已核实的预设见 `src/core/config/providers.js`；目录和模型可能调整，实际可用性以连接测试为准。

通用答疑提示词在 `src/core/ai/prompts.js`：读清条件、解释方法选择、检查适用前提与易错点、不确定直说、使用 Markdown + KaTeX，不固定自然语言定性，不输出掌握度 / 骨架标签。出题 / 批改 / 后台归位提示词分别独立，不依赖专属思考模式。

流式适配及文件设计见 [技术记录](../docs/流式与附件实现.md)，暂定方案和延后想法见 [后续计划](../docs/后续计划与待调整.md)。
