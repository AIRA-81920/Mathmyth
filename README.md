# Mathmyth

> 做完一道题，它告诉你你到底做了什么。

大多数搜题软件在你抄下答案的那一刻就结束了。Mathmyth 会在给你解答的同时，把这道题钉到一张
「情景 → 方法」的网上：它属于哪一类题、该用哪个方法、什么时候该换成别的方法，以及**你现在掌握到哪一步**。

电脑和手机都能用，不用注册账号，题目和记录只存在你自己的设备上。

---

## 它到底做了什么

**解题。** 贴一道题，文字或截图都行，公式用 KaTeX 排版。模型在讲解答的同时把图里的题面转写下来，
你可以直接改、直接追问。PDF、Word、纯文本附件也能进来（单文件 25 MiB、PDF 20 页、文本 8 万字以内）。

**归类。** 解答之后，这道题会被挂到知识骨架上：属于哪个情景、走了哪个方法、这条路上还有哪几个方法可以走。
所以下次遇到"看起来不一样"的题，你能认出它其实是同一类。

**记录。** 足迹记的不是"你搜过多少题"，而是你走到了哪：见过、会用、掌握。
规则很克制——认出要累计 3 次、覆盖 3 种结构不同的题面；用出要累计 2 次、覆盖 2 道实际题；
重复的原题每个维度只记一次；**答错不清空题面，看答案不记功，也不按时间降级**；已经掌握的题答错会退回「巩固中」。
它不制造焦虑。

**练习。** 练习考的不是"算出答案"，而是**选对路线**：判断这题该用哪个方法、辨认给出的路线是否可行、
比较两条路线哪个更符合标准，最后才写关键步骤。优先用已审核题库，题不够时才让 AI 编变式，AI 草稿不计入掌握度。

**接着这道题试。** 回答末尾有「本题路径」「试一道相关题」「收藏原题」。精准随练同时检查题目结构和有顺序的情景、方法链；
有多条路径时先让你选，没有匹配时明确说明。短练习可以直接写关键步骤，也可以先选路线，提示逐层展开。
结束时分别说明这次已经检验什么、还有什么没检验。首批精准匹配覆盖四类极限结构，其他题型继续使用问答与练习入口。

**两个学科。** 高等数学和高中数学各有独立的知识骨架、题库与记录，数据分开保存，随时在设置里切换。

**自己的题也算数。** 作业题、教材题随便问，不限于内置题库；所有归类、足迹、掌握度都是从你自己的题长出来的。

## 它和别的做题软件不一样在哪

| 常见做法 | Mathmyth |
|---|---|
| 给答案，结束 | 给答案，然后告诉你这题是什么、还能怎么走 |
| 记录搜过多少题 | 记录你掌握了什么、掌握到哪一级 |
| 练习只考算出答案 | 练习先考"选对方法"，再考"算对" |
| 答错扣分、连续打卡 | 答错不清空题面，看答案不记功，不按时间降级 |
| 账号 + 云端 | 不要账号，数据只在本机，随时导出/导入 |
| 只能打字问 | 拍照、截图、PDF、Word、纯文本都能进来 |

## 三步上手

1. 首次打开，先选你在学的数学（高数 / 高中数学），再填自己的模型服务和 Key，按模型真实能力勾选"支持图片"。
   中间的本地示例可以跳过，示例不会写入个人学习记录。
2. 贴题或拍照，看它讲——看到不认的地方直接追问。
3. 看回答末尾的本题路径，按需试一道相关题；也可以进入练习页自行选择。设置里可以重新体验引导。

## 装在哪

| 平台 | 文件 | 说明 |
|---|---|---|
| 手机 | `artifacts/Mathmyth-v4.2.1-release.apk` | Android 7 及以上，正式签名 |
| 电脑 | `artifacts/desktop/Mathmyth-v4.2.1-Setup.exe` | Windows x64 安装包，未做正式签名 |

**从 3.1.0 升级的注意**：早期发布的 APK 是调试签名，安卓不允许直接覆盖安装。请先「设置 → 数据 → 导出到文件」
保存备份，卸载旧版后再装这个包，装好后打开「设置 → 数据 → 导入」。从 4.2.1 起，以后升级可以直接覆盖安装。

两端数据各自独立，靠一个 `.sqlite` 备份文件导出/导入迁移。桌面数据在 `%APPDATA%\Mathmyth`，卸载不会删掉学习记录。

## 数据与隐私

- **没有账号、没有云同步、没有 Node 后端。** SQLite 跑在浏览器的 Worker 里，快照提交到 IndexedDB；桌面端同一套机制。
- **安装包不带你的 Key。** 打包脚本会在网页资产和最终 APK/ASAR 上检查密钥、环境文件、私钥和备份文件，发现可疑内容直接阻止交付。
- 你主动导出的备份包含会话、题图、学习记录和模型选项，不含 API Key。导入时保留当前设备已有的有效模型配置；新设备需要填写 Key。
- 除了你自己提问时发给所选模型服务商的内容，题目和记录不会离开这台设备。

## 自己跑 / 自己打

需要 Node 20+。开发端口固定 5197，预览端口固定 4197。

```powershell
cd frontend
npm ci
npm run dev        # http://127.0.0.1:5197
npm run build
npm run preview    # http://127.0.0.1:4197
npm test           # 452 项自动测试（4.2.1 验证记录）
```

打包两端：

```powershell
npm run android:build     # 项目内自带 SDK 36 / JDK 21
npm run desktop:build     # Windows x64 NSIS
```

无交互构建两端正式包：
`powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-package.ps1 -Target all -Version 4.2.1 -NoPrompt -Release`

打包脚本会显示当前版本与 Android versionCode，换版本会自动 +1，保证能覆盖安装。
签名材料（`android/keystore*`、`keystore.properties`）与产物（`artifacts/`、`dist/`）都不进仓库。

- **流式与渲染**：网页 SSE、安卓原生 HTTP、桌面原生 HTTP 共用同一解析器；Markdown 只在完整块、代码、公式、链接和列表边界提交检查点，

- **附件**：点附件先收键盘，再在输入框下展开「最近图片 / 拍照 / 相册 / 文件」。本机解析 JPEG/PNG/GIF/WebP、
  纯文本（UTF-8 / UTF-16 / GB18030）、.docx（公式保留为 LaTeX：分隔符、积分与求和的上下限、方程组、重音、函数名、文本框不重复）、
  Word 97–2007 .doc 主文本、PDF；PDF 对多模态模型同时保留页面图像。超限会说明原因，不静默截断；
  读不懂的文件给中文提示，不会把英文异常甩给用户。选图后可以裁切，发送时只提交裁切结果。
- **历史**：长按/右键提供置顶、重命名、删除；删除可选"只删聊天"或"同时移除这段聊天产生的足迹"，前者保留题面摘要与掌握度。
  首条内容会异步生成不超过 20 字的标题，手动重命名优先；抽屉可搜索标题、正文和附件提取的文字。
- **足迹**：板块、分组、情景点信息图标可看定义与特征；方法的适用情景和情景关联方法可以互相跳转，返回时保留展开与阅读位置。
  展开与滚动状态全局保存，只有开新对话才重置。滚动位置在停手后落盘，不会每滚一下就写一次数据库。
- **练习**：三层递进——单选任一有效路线、辨认给出的所有有效路线、区分"可行"与"更符合标准"，最后写实际关键步骤。
  未提交就点「下一道」、或在还有没练完的一轮时点「开练」，都会先确认；未提交的输入会保留为草稿。
  草稿按题保存，退出、切后台、关闭应用时会立刻补写一次，重开可以接着写。
  "练习记录"可回看原题、当时的选项或步骤、反馈与解答；查看解答会记为已揭示，之后不再计该题独立成功。
  提示、帮助反馈、原始作答和异议随记录保存，后来查看帮助不会抹掉此前已保存的独立成功。复习由你主动安排，可以撤销。
  后台归位不阻塞答疑；前台开始回答或开始检查练习会立刻让出模型连接，归位稍后从检查点继续。
- **外观**：浅色为轻微暖白、深色主背景纯黑，可跟随系统，跨重启保留；顶部三个区域的指示线会跟着手指走。
- **服务商**：保留用户填写的五家地址，默认模型可编辑，图片能力由用户勾选，切换预设不改用户开关；
  已核实的预设见 `src/core/config/providers.js`，实际可用性以连接测试为准。

## 已知限制

- Android 提供正式签名包；Windows 安装包未做代码签名，SmartScreen 可能提示。应用可以检查版本，安装更新仍由用户操作。
- 从 3.1.0 这类调试签名包升级需要先导出备份、卸载再装（见上面「装在哪」）。
- 精准随练首批支持四类可识别的极限结构，不支持的结构不会借用同标签题冒充精准匹配。AI 草稿仍需核验，不计入掌握度。
- PDF 的公式按文字层提取，复杂分式与上下标可能错序；含重要公式的 PDF 建议直接截图发送。
- 数学质量取决于你填的模型，App 只负责组织、记录与呈现。
- 桌面端不包含工作区、浏览器配置或 `.env`；Electron 渲染进程不开 Node，原生能力走窄 IPC。
